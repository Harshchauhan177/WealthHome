🏠 WealthHome

WealthHome is a full-stack real estate web application that enables users to buy, rent, and list properties with ease. The frontend is built using HTML, CSS, and JavaScript, while the backend leverages Supabase for user authentication, data storage, and real-time property listings.


✨ Features
🏡 Browse properties available for buying and renting
📝 Submit new property listings via a responsive form
🔐 User authentication using Supabase Auth
📦 Store and manage property data using Supabase Database
📱 Fully responsive design for desktop and mobile
🗂️ Organized UI for buyers, renters, and property owners


🛠️ Tech Stack
Frontend: HTML, CSS, JavaScript
Backend: Supabase (Auth, Realtime DB)
Version Control: Git & GitHub


🚧 Project Status
WealthHome is in active development. Core frontend is complete, and backend features like authentication and property management are being integrated via Supabase.
